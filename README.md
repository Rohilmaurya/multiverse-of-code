# 🟢 Multiverse of Code: LATVERIAN_OS

> **GFG Student Chapter × Marvel** crossover event landing page.

![Banner](assets/images/luma_event_poster.jpg)

## 📖 Overview
**Multiverse of Code** is an immersive, cinematic, single-page web experience built for the GeeksforGeeks Student Chapter. Originally designed as a standard tech event landing page, the narrative follows a "system override" by Marvel's Dr. Doom, completely hijacking the interface and turning it into a retro, hacker-themed terminal—the *Latverian OS*.

This project pushes the boundaries of standard static web development, featuring highly choreographed scroll-linked animations, native Web Audio synthesis, HTML5 Canvas rendering, and deep CSS trickery to simulate a CRT monitor environment.

## ✨ Features
* **Interactive Matrix Rain**: Custom HTML5 Canvas rendering engine creating tactical-green digital rain with randomized decryption runes.
* **Scroll-Linked Physics**: A 500vh introductory sequence entirely driven by vanilla JavaScript scroll interpolation.
* **Dynamic Web Audio Synthesis**: Procedurally generated 800Hz keystroke blips and 50Hz sawtooth glitch waves that sync with the on-screen animations (no external audio files required for UI sounds).
* **Cinematic Transitions**: Features a dramatic CRT "TV Power-Off" transition, anamorphic letterboxing, and aggressive CSS filter blooms.
* **Global Thematic Styling**: 100% custom CSS (no frameworks). Features a global CRT scanline overlay, glowing monospace typography, toxic-green hover states, and parallax background sigils.
* **Spider-Man Easter Eggs**: Hidden sound effects (`thwip.mp3`) and rare text-glitches (`PARKER_PROTOCOL_DETECTED`) scattered throughout the timeline.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure and accessibility.
- **CSS3**: Variables, Flexbox/Grid, Keyframe Animations, CSS Filters (Sepia, Hue-Rotate, Drop-Shadow).
- **Vanilla JavaScript**: Intersection Observers, Canvas API, Web Audio API, Custom smooth-scroll inertia mapping.

## 🚀 Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/marvel-gfg.git
   ```
2. Navigate into the directory:
   ```bash
   cd marvel-gfg
   ```
3. Run a local web server (required for Web Audio API and CORS). For example, using Python:
   ```bash
   python -m http.server 8000
   ```
4. Open your browser and navigate to `http://localhost:8000`.
